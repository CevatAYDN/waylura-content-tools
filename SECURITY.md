# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `waylura-content-tools`, please report it responsibly by contacting the project maintainers via GitHub Security Advisories or direct communication.

Do not publish security issues publicly until a patch or mitigation is available.
